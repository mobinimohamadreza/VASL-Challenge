# بازی مین روب (Minesweeper)

یک بازی مین روب کلاسیک با استفاده از React + TypeScript + Vite + Tailwind CSS + Zustand

## ویژگی‌ها

- صفحه شطرنجی 16x16
- 40 مین به صورت تصادفی
- کلیک چپ برای آشکار کردن سلول
- کلیک راست برای علامت‌گذاری مین‌های مشکوک
- آشکار شدن خودکار سلول‌های مجاور (flood fill) وقتی تعداد مین‌های مجاور 0 است
- نمایش تعداد مین‌های مجاور هر سلول
- تشخیص برنده/بازنده

## نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای پروژه در حالت توسعه
npm run dev

# ساخت نسخه production
npm run build

# پیش‌نمایش نسخه production
npm run preview
```

## تکنولوژی‌ها

- **Vite** - Build tool و dev server
- **React** - کتابخانه UI
- **TypeScript** - زبان برنامه‌نویسی
- **Tailwind CSS** - استایل‌دهی
- **Zustand** - مدیریت state

## نحوه بازی

1. کلیک چپ روی یک سلول برای آشکار کردن آن
2. اگر سلول حاوی مین باشد، بازی تمام می‌شود
3. اگر سلول خالی باشد، تعداد مین‌های مجاور نمایش داده می‌شود
4. کلیک راست برای علامت‌گذاری/حذف علامت مین مشکوک
5. هدف: آشکار کردن تمام سلول‌های غیر مین

## ساختار پروژه

```
src/
├── components/     # کامپوننت‌های React
│   └── Cell.tsx    # کامپوننت سلول
├── store/          # مدیریت state با Zustand
│   └── gameStore.ts
├── utils/          # توابع کمکی
│   └── gameLogic.ts
├── types.ts        # تعریف انواع TypeScript
├── App.tsx         # کامپوننت اصلی
├── main.tsx        # نقطه ورود
└── index.css       # استایل‌های Tailwind
```
